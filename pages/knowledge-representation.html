01 / Text Encoding

TEI Encoding

A selected sample of the English Wikipedia article on James Bond was encoded in TEI/XML. Passages were selected according to their relevance to the research question and to the entities represented in the project; omitted passages are explicitly marked with <gap reason="sampling">.

The TEI header records the source and the entities required by the selected text, associates local identifiers with external authority URIs through @sameAs, defines the classifications used by the project and includes a <listRelation> expressing the semantic relations that apply to the encoded sample.

02 / Transformation

TEI to HTML

The encoded TEI sample was transformed into HTML through an XSLT stylesheet. Structural divisions and headings are converted into HTML sections, while titles, quotations and annotated entities retain a distinct visual treatment. Sampling gaps remain visible in the resulting page rather than being silently removed.

A short Python script based on lxml applies the stylesheet to 007_tei.xml and writes the resulting document as 007_tei.html.

03 / Semantic Transformation

TEI to RDF

The same TEI document was also used as a source for RDF production. A Python script parses the XML and converts the semantic information encoded in the header into RDF triples using RDFLib.

Local entities are reconciled with external resources by converting @sameAs values into owl:sameAs statements, while <relation> elements become RDF triples. The transformation also generates resource labels, typed literal values and authority reconciliation statements before serialising the graph in Turtle and parsing it again as a validation step.

The resulting 007_tei.ttl represents the entities and relations contained in the selected TEI sample. It should therefore be read as a TEI-derived subset rather than as the complete 00LOD dataset.

04 / Metadata Transformation

Metadata to RDF

The complete project dataset was generated from the structured metadata collected for the fourteen Mission Files. In items.csv, each row expresses a subject, predicate and object together with the information required to distinguish local resources, external URIs and literal values.

The Python transformation resolves local identifiers and prefixed names, creates the corresponding RDF terms and serialises the resulting graph as dataset_bond.ttl. The generated Turtle file is parsed again to verify that the output is valid RDF.

Together, the TEI- and metadata-based workflows translate the selected sources and descriptive data into interoperable RDF representations. By connecting the fourteen Mission Files through shared identifiers, classifications and semantic relations, the resulting Linked Data network makes explicit the associations through which James Bond is represented as a cultural icon.
